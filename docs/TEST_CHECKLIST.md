# Test checklist

Mark an item only after you have run it.

## Phase 1 (repository and page)
- [ ] `npm install` completes
- [ ] `npm test` shows all tests passing
- [ ] `npm run build` creates `dist/`
- [ ] `npm run dev` opens the page on the laptop
- [ ] GitHub Actions workflow succeeds
- [ ] `https://<username>.github.io/yogai-phone-tracker/` opens on the laptop
- [ ] The same URL opens on the Android phone
- [ ] Phone compatibility screen: note what it says for Camera, Web Serial and WebUSB
- [ ] Chrome menu → Install app / Add to Home screen is offered (optional)

## Later phases
Phase 2 camera, Phase 3 MediaPipe, Phase 4 controller simulation, Phase 5 USB (one motor at a time), Phase 6 full tracking, Phase 7 wireless, Phase 8 YogAI links. Detailed steps are added with each phase.
